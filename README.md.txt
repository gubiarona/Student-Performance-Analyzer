
# Student-Performance-Analyzer

## Project Description

The Student Performance Analyzer is a Python-based application designed to manage and analyze student academic performance. The system allows users to input student information, calculate average scores, assign letter grades, rank students, and generate performance reports. It applies Object-Oriented Programming (OOP) principles such as encapsulation, abstraction, and modularity to ensure an organized and maintainable system.

## Features

* Store student information and subject scores
* Calculate average scores automatically
* Assign letter grades (A–F)
* Rank students based on academic performance
* Generate and display student performance reports
* Organized using Object-Oriented Programming concepts

## Class Structure

### Student Class

* Stores student name, scores, average, and grade
* Provides methods for accessing and updating student information

### GradeProcessor Class

* Calculates averages
* Assigns letter grades
* Ranks students according to performance

### OutputWriter Class

* Formats and displays reports
* Presents student records, grades, averages, and rankings

## Grade Scale

| Score Range | Grade |
| ----------- | ----- |
| 90–100      | A     |
| 80–89       | B     |
| 70–79       | C     |
| 60–69       | D     |
| Below 60    | F     |
